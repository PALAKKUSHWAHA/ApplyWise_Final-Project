## 🎯 Common Tasks

### "I want to install and start using"
```
1. Read: INSTALLATION_CHECKLIST.md
2. Install Ollama
3. Run: ollama pull mistral
4. Run: ollama serve
5. Start backend & frontend
6. Visit: http://localhost:3000/ai-assistant
```

### "I want to use a different model"
```
1. Read: SETUP_AI_ASSISTANT.md - Model Comparison
2. Download: ollama pull llama2 (or other model)
3. Edit: backend/.env
4. Set: LLM_MODEL=llama2
5. Restart backend
```

### "I want to use OpenAI instead"
```
1. Read: AI_IMPLEMENTATION_GUIDE.md - Configuration Options
2. Get: OpenAI API key
3. Edit: backend/.env
4. Set: LLM_PROVIDER=openai
5. Set: OPENAI_API_KEY=sk-...
6. Restart backend
```

### "I want to understand the code"
```
1. Read: IMPLEMENTATION_COMPLETE.md
2. Read: AI_IMPLEMENTATION_GUIDE.md
3. Review: VISUAL_GUIDE.md - Architecture section
4. Study: Source files in backend/ and frontend/
```

### "Something isn't working"
```
1. Check: INSTALLATION_CHECKLIST.md - Troubleshooting
2. Read: SETUP_AI_ASSISTANT.md - Troubleshooting
3. Verify:
   - Ollama is running: ollama serve
   - Backend is running: http://localhost:8000/docs
   - Frontend is running: http://localhost:3000
   - Model is installed: ollama list
```
